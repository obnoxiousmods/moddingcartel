📦 What's in CartelPack?

The CartelPack includes everything you need:

  • moddingcartel.exe - USB & FTP extension for sending games to your Switch
  • nsusbloader_installer.exe - NS USBLoader installer
  • nswdrivers.exe - Nintendo Switch USB drivers installer
  • switch/sphaira - Sphaira homebrew (installer + launcher + FTP)
  • switch/tinwoo - TinWoo installer (HTTP + USB + Network support)

🚀 Complete Setup Guide

1
Download CartelPack

Get cartelpack.zip from below and extract it to a folder on your PC

2
Install USB Drivers

Run cartelpack/nswdrivers.exe and follow the installer. May require reboot for USB method to work

3
Connect Switch to Network

Connect your Nintendo Switch to the same network as your PC (Ethernet or WiFi both work). If using FTP method, no reboot needed!

4
Prepare SD Card
  • Boot into Hekate and mount SD card to PC, OR
  • Turn off Switch, remove microSD, and use a microSD reader (USB adapter or phone)
  • Important: You must have SuperZip OR HATS pack already installed on your Switch!
5
Install Switch Software

Copy the contents of cartelpack/switch/ folder (sphaira and tinwoo folders) to your microSD card's /switch/ directory

6
Boot Your Switch

Eject the SD card safely, put it back in your Switch, and boot into CFW (Atmosphere)

7
Open Sphaira
  • Launch any game while holding R button on the right joycon to open hbmenu
  • If hbmenu appears, find and launch Sphaira from the menu
  • Alternatively, press Album button to access homebrew launcher, then open Sphaira
  • Tip: Applet mode works fine for installing smaller games. For larger games, use "Game Mode" (hold R while launching a game)
  • Optional: In Sphaira settings, you can replace hbmenu entirely (recommended for ease of use)
8
Enable Transfer Methods in Sphaira
  • In Sphaira, press Y → Menu → FTP Install → Enable
  • Do the same for USB Install (Y → Menu → USB Install → Enable)
  • Navigate to the FTP Install or USB Install menu and keep Sphaira ready to receive files
9
Run moddingcartel.exe
  • Launch cartelpack/moddingcartel.exe from your PC
  • The program will prompt you to sign in with your ModdingCartel account
  • If you don't have an account, sign up at moddingcartel.com (just username + password, no email/SMS required, free!)
  • When asked for website/hostname, just press Enter (uses default)
10
Configure Switch IP Address
  • When prompted for Switch IP, you can manually enter it, OR
  • Press Enter to auto-scan (automatically scans 192.168.*.* and 10.0.*.* ranges)
  • The app verifies the IP on launch - if unreachable, it will rescan automatically
  • Find your Switch's IP: In Sphaira or Switch System Settings → Internet → Connection Status
11
Start Installing Games!
  • If successful, you'll see "Ready! Start adding games to the queue..."
  • Go to moddingcartel.com and add games to your queue
  • moddingcartel.exe will automatically download and send them to your Switch!
  • Games install directly to your Switch - no manual file transfers needed

💡 Tips & Troubleshooting

Configuration Files: Config file (config.yaml) and log file (send_to_switch.log) are stored in the same directory as moddingcartel.exe. Check the log file if you encounter problems.
Manual IP Configuration: You can manually edit the Switch IP address in config.yaml if needed. The auto-scanner searches 192.168.*.* and 10.0.*.* network ranges.
Transfer Speed: USB transfers are significantly faster than FTP! The client automatically detects and prioritizes USB when both are available.
Error Handling: If the program crashes, neither USB nor FTP is working properly. Ensure:
  • USB drivers are installed correctly (may need reboot)
  • PC and Switch are on the same network (for FTP)
  • Sphaira is running and in the correct install mode
  • Switch IP is correct (check in Switch network settings)
Window Behavior: When built as an .exe, the window stays open on error so you can read the error message. Press Enter to close it.
